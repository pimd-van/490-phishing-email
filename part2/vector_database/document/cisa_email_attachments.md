# Using Caution with Email Attachments

This file is a condensed, source-grounded adaptation of the official CISA page, not a verbatim copy of the complete page.

This CISA page is archived and warns that archived information may not reflect current policy or programs.

## Why can email attachments be dangerous?

Some characteristics that make email attachments convenient and popular also make them a common tool for attackers. Email is easily circulated, almost any type of file can be attached, and some email programs automatically download attachments. Attackers can spoof return addresses, so a message that appears to come from someone familiar is not necessarily legitimate.

## Steps to protect yourself and others

- Be wary of unsolicited attachments, even from people you know. If possible, confirm with the supposed sender before opening an attachment. Internet service providers and software vendors do not send patches or software in email.
- Keep software up to date and enable automatic operating-system updates when available.
- Trust your instincts. Do not open a suspicious email or attachment merely because antivirus software says it is clean; new malware may not yet have a known signature.
- If an attachment must be opened before its source can be verified, update antivirus signatures, save the file, manually scan it, and open it only if it is clean and does not seem suspicious.
- Turn off automatic attachment downloads.
- Consider reading email using an account with restricted privileges rather than administrator privileges.
- Apply additional security practices, such as filtering certain attachment types through email software or a firewall.
