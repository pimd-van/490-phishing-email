กลุ่มอีเมล phishing ของ Linear SVM

อีเมลใน test set ของ MeAJOR ที่ Linear SVM ทำนายว่าเป็น phishing จัดเป็นกลุ่มแม่และกลุ่มย่อยตามความหมาย แล้วสุ่ม 700 แถวตามสัดส่วนจำนวนอีเมลของแต่ละกลุ่มย่อย

แผนที่ความหมาย (t-SNE)

แต่ละจุดคืออีเมลหนึ่งฉบับ จุดที่อยู่ใกล้กันมีความหมายคล้ายกัน สีบอกกลุ่มแม่ เฉดบอกกลุ่มย่อย ชี้เพื่อดูหัวเรื่อง คลิกกลุ่มทางขวาเพื่อเน้น

ลำดับชั้นของกลุ่ม

แถบ = จำนวนอีเมล, ตัวเลขขวาสุด = จำนวนที่สุ่มเข้า 700 แถว

Dendrogram

ความสูงที่สองกิ่งมาบรรจบกันคือระยะ Ward ตอนรวมกัน ยิ่งต่ำยิ่งคล้ายกัน สีบอกกลุ่มแม่ เส้นประบอกระดับที่ตัดเป็นแต่ละชั้น เลือกความลึกด้านล่าง แล้วคลิกขาของกลุ่มเพื่อดูรายละเอียดและรายชื่ออีเมลในกลุ่มนั้น

รายละเอียดกลุ่มย่อย

ชื่อและคำอธิบายกลุ่มสร้างโดย LLM จากคำเด่นและอีเมลตัวอย่าง ควรให้คนตรวจทานก่อนใช้ คำเด่นคำนวณแบบ c-TF-IDF อีเมลตัวอย่างคือ 3 ฉบับที่ใกล้จุดศูนย์กลางของกลุ่มที่สุด
